**核心玩法循环**

**经营层（宏观）**

1. **接单**：在“蘑菇屋”经营界面查看奇幻生物订单（如“帮史莱姆搬果冻床”“帮云朵羊搬彩虹枕头”），评估难度（风力、粘性、漂浮属性）。

3. **出发**：点击订单加载对应奇幻关卡，进入搬运执行阶段。

**执行层（微观）**

1. **搬运**：玩家操控毛茸茸的动物小精灵，分工合作搬运Q弹货物，应对场景互动（如被史莱姆粘住、被风吹跑）。
2. **应对**：处理“可爱型麻烦”——用零食引开贪吃的松鼠客户、用喇叭叫醒挡路的瞌睡虫队友、用绳子固定被风吹走的羽毛枕头。
3. **结算**：根据完成度（时间、货物完好率、客户满意度）获得1-3颗星评价，解锁新订单与道具。

**动物职业系统（核心策略）**

我们将角色设计为不同动物，每种动物拥有独特的“生理天赋”与“可爱烦恼”，玩家需根据关卡特性组建小队。

**巨力组：陆地巡洋舰**

• **代表角色**：水豚、黑熊、大象

• **核心天赋**：

◦ **不动如山**：负重上限极高（可以搬冰箱、钢琴），行走时不会被风吹动，不会被撞退。

◦ **重压**：可以压住翘起的地板、或者压住乱动的货物。

• **可爱烦恼**：

◦ **笨重**：移动速度慢，转身慢，无法冲刺。

◦ **怕高**：无法通过狭窄的独木桥（会掉下去），无法进入小型洞穴。

• **适合任务**：重型家具搬运、需要抗风的云层关卡。

• **不适合任务**：精细操作（如搬运水晶灯）、需要跳跃的关卡。

**灵巧组：高空杂技**

• **代表角色**：松鼠、浣熊、红熊猫

• **核心天赋**：

◦ **飞檐走壁**：可以在墙壁上短暂奔跑（绕过地上的障碍），可以走钢丝。

◦ **极速搬运**：移动速度极快，搬运轻小物品（如餐具、花瓶）有加成。

• **可爱烦恼**：

◦ **力气小**：无法搬运重物（搬大箱子会趴下），容易被大风吹跑。

• **适合任务**：狭窄地形、需要跑酷的关卡、易碎品搬运。

• **不适合任务**：重型家具、暴风雪山庄（会被吹飞）。

**飞行组：空中运输队**

• **代表角色**：猫头鹰、鹦鹉、飞鼠

• **核心天赋**：

◦ **无视地形**：可以短距离飞行（跳过深渊、河流），或者滑翔。

◦ **上帝视角**：可以飞到高处点亮地图迷雾，发现隐藏捷径。

• **可爱烦恼**：

◦ **负重极低**：只能搬运极轻的物品（如气球、羽毛），搬运重物时会直接坠机。

◦ **怕封闭**：在狭窄的管道或地下关卡，翅膀施展不开，速度变慢。

• **适合任务**：跨岛屿搬运、悬崖关卡、寻找隐藏物品。

• **不适合任务**：地下迷宫、狭窄管道。

**特殊组：异能专家**

• **代表角色**：章鱼、史莱姆（拟态）、变色龙

• **核心天赋**：

◦ **多手抓握**：章鱼可以同时搬运4个小物品（如一次搬一套茶具）。

◦ **吸附/变色**：可以爬天花板（变色龙），或者身体变软穿过栅栏（史莱姆）。

• **可爱烦恼**：

◦ **脱水/干燥**：在沙漠或高温关卡会持续掉血（需要队友浇水）。

◦ **移动怪异**：操作手感与常人不同，需要适应。

• **适合任务**：复杂地形、多物品收集、特殊机关解谜。

• **不适合任务**：高温环境、干燥沙漠。
